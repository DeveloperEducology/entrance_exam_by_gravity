Adding and Subtracting Integers

An integer is a number without a fractional part. Integers can be positive, negative, or zero. You can add and subtract integers using models like number lines and counters, or by following specific algebraic rules.

1. Adding Integers on a Number Line

To add integers on a number line:

Find the first addend on the number line.

Move for the second addend:

To add a positive number, move to the right.

To add a negative number, move to the left.

The sum is the number where you land.

Example 1: Adding a Positive Integer

Equation: $-3 + 5$

Start at $-3$.

Move 5 units to the right because 5 is positive.

You land on 2.

Result: $-3 + 5 = 2$

Example 2: Adding a Negative Integer

Equation: $4 + (-7)$

Start at $4$.

Move 7 units to the left because $-7$ is negative.

You land on $-3$.

Result: $4 + (-7) = -3$

2. Rules for Adding Integers

You can solve addition problems without a number line by looking at the signs:

Same Signs: Add the absolute values and keep the sign.

Example: $-4 + (-6) \rightarrow 4 + 6 = 10 \rightarrow$ $-10$

Different Signs: Subtract the lesser absolute value from the greater. Give the sum the sign of the number with the greater absolute value.

Example: $-4 + 6 \rightarrow 6 - 4 = 2$. Since $6$ is greater than $|-4|$, the answer is positive $2$.

3. Using Integer Counters

Counters are visual tools where a positive counter (+) and a negative counter (-) together create a zero pair (value of 0).

Modeling $-4 + 6$

Start with 4 negative counters.

Add 6 positive counters.

Cross out the 4 zero pairs.

2 positive counters remain.

4. Subtracting Integers

Rule: Subtracting a number is the same as adding its opposite.
To subtract, rewrite the expression as addition, then follow addition rules.

Steps:

Keep the first number.

Change subtraction to addition.

Change the sign of the second number (to its opposite).

Example 1: Subtracting a positive
$3 - 7 \rightarrow 3 + (-7) = \mathbf{-4}$

Example 2: Subtracting a negative
$-2 - (-5) \rightarrow -2 + 5 = \mathbf{3}$
