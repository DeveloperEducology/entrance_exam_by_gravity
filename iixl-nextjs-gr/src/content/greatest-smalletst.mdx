### **Topic: Forming the Greatest Number using Given Digits (3-digit, 4-digit, 5-digit)**

#### **Learning Objective**
By the end of this lesson, you will be able to:
- Form the **greatest possible number** using given digits **without repeating** any digit.
- Understand why we arrange digits in **descending order**.
- Apply the same method for **3-digit**, **4-digit**, and **5-digit** numbers.

---

#### **Key Rule (Very Important)**

> **To form the GREATEST number, always arrange the digits in DESCENDING ORDER**  
> (from **biggest digit** to **smallest digit**)

**Descending Order** means: **Largest → Smallest**

---

### **Step-by-Step Method**

1. **List all the given digits**
2. **Arrange them from biggest to smallest** (Descending order)
3. **Write them together** to form the number

**Special Rule for 0 (Zero):**
- Never put **0** in the first place (thousands/hundreds place) because it will not remain a 4-digit or 5-digit number.

---

### **Example 1: 4-Digit Number** (as shown in your image)

**Digits given:** 0, 9, 4, 5  
(Use each digit only once)

**Step 1:** List digits: 0, 9, 4, 5  
**Step 2:** Arrange in descending order: **9, 5, 4, 0**  
**Step 3:** Form the number: **9540**

**Correct Answer: 9540**

**Why others are wrong:**
- 4590 → Starts with smaller digit
- 0495 → This is actually 495 (only 3-digit number)
- 0459 → This is actually 459 (only 3-digit number)

---

### **More Examples**

#### **Example 2: 3-Digit Number**

**Digits:** 2, 7, 1

**Descending order:** 7, 2, 1  
**Greatest number:** **721**

#### **Example 3: 3-Digit Number (with zero)**

**Digits:** 0, 8, 3

**Descending order:** 8, 3, 0  
**Greatest number:** **830**  
(Do not write 083 — that becomes 83, a 2-digit number)

#### **Example 4: 5-Digit Number**

**Digits:** 3, 9, 1, 7, 4

**Descending order:** 9, 7, 4, 3, 1  
**Greatest number:** **97431**

#### **Example 5: 5-Digit Number (with zero)**

**Digits:** 0, 6, 8, 2, 5

**Descending order:** 8, 6, 5, 2, 0  
**Greatest number:** **86520**

### **Quick Practice Questions**

**Q1.** Digits: 1, 6, 0 → Greatest **3-digit** number?  
**Answer:** 610

**Q2.** Digits: 7, 2, 9, 3 → Greatest **4-digit** number?  
**Answer:** 9732

**Q3.** Digits: 4, 0, 8, 1, 5 → Greatest **5-digit** number?  
**Answer:** 85410

**Q4.** Digits: 9, 9, 5, 0 → Greatest **4-digit** number?  
**Answer:** 9950  
(Note: You can repeat 9 because it appears twice)

---

### **Summary (Must Remember)**

- **Greatest number** = Digits arranged in **Descending order** (Big to Small)
- Always start with the **largest digit**
- **Never** start with **0**
- Use each digit **only as many times** as it is given

---

### **Common Mistakes to Avoid**
- Putting 0 at the front
- Arranging in ascending order (small to big) → that gives the smallest number
- Forgetting to use all digits
