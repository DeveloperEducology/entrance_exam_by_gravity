# Understanding Place Value and Face Value
**Target Level: Class 5**

In mathematics, every digit in a number has two different "values." To understand numbers correctly, we need to know the difference between what a digit **looks like** (Face Value) and **where it lives** (Place Value).

---

## 1. What is Face Value?
The **Face Value** of a digit is simply the digit itself. It never changes, no matter where the digit is placed in a number.

* **Analogy:** Your face stays the same whether you are at home, at school, or at the park.
* **Example:** In the number **84,410**, the Face Value of **8** is just **8**.

---

## 2. What is Place Value?
The **Place Value** of a digit depends on its position (place) in the number. As a digit moves to the left in a number, its value increases by 10 times at each step.

* **Analogy:** If you sit in the "Pilot's Seat" on a plane, you have more responsibility than if you sit in a "Passenger Seat," even though you are the same person!



### Place Value Chart for 84,410
We use this scaffold table to see exactly where each digit "lives."

| Ten Thousands (T-Th) | Thousands (Th) | Hundreds (H) | Tens (T) | Ones (O) |
| :---: | :---: | :---: | :---: | :---: |
| **8** | 4 | 4 | 1 | 0 |
| $8 \times 10,000$ | $4 \times 1,000$ | $4 \times 100$ | $1 \times 10$ | $0 \times 1$ |
| **80,000** | 4,000 | 400 | 10 | 0 |

---

## 3. The Digit 8 in 84,410
Let’s look specifically at the digit **8** to solve your problem:

| Feature | Value | Explanation |
| :--- | :--- | :--- |
| **The Digit** | 8 | This is the number we are focusing on. |
| **Face Value** | **8** | It is just the number itself. |
| **Place Value** | **80,000** | Because the 8 is in the "Ten Thousands" place. |

### Calculating the Difference
"Difference" in math means we need to **subtract**.

$$Place\ Value - Face\ Value = Difference$$
$$80,000 - 8 = 79,992$$

## 5. Example Practice Problems

### Problem 1: Finding the Sum (Addition)
**Q:** What is the **sum** of the place value and face value of the digit **1** in **84,410**?
* **Method:** Place Value (10) + Face Value (1).
* **Answer:** $10 + 1 = 11$.

### Problem 2: Comparing Two Digits
**Q:** How many times greater is the place value of the **4** in the thousands place than the **4** in the hundreds place?
* **Method:** Divide the larger place value by the smaller one ($4,000 \div 400$).
* **Answer:** **10 times** greater.

### Problem 3: The "Zero" Rule
**Q:** In the number **84,410**, which digit has a face value and place value that are exactly the same?
* **Rule:** This only happens at the "Ones" place or when the digit is 0.
* **Answer:** The digit **0** (its place value is $0 \times 1 = 0$).

### Problem 4: Word Puzzle
**Q:** Write a number where the place value of **5** is **5,000** and the face value of the digit in the tens place is **2**.
* **Method:** Put 5 in the Thousands column and 2 in the Tens column. Fill others with 0.
* **Answer:** **5,020**.

**Final Answer to your question:**
The difference between the place value (80,000) and the face value (8) of the digit 8 in 84,410 is **79,992**.
