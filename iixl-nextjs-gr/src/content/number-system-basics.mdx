This lesson is designed specifically for **slow learners**, using the "Building Block" approach. We start with the simplest numbers we use as children and layer on complexity one step at a time.

---

# Lesson: The Number System Family
**Goal:** To understand how different types of numbers relate to each other.

---

## 1. Natural Numbers ($\mathbb{N}$)
**The "Counting" Numbers**
Think of these as the numbers you use to count objects (like apples or pens). You never start counting at zero or use negatives for physical objects.

<Practice

* **Definition:** Numbers starting from 1 and going up to infinity.
* **Symbol:** $\mathbb{N} = \{1, 2, 3, 4, 5, \dots\}$
* **Simple Example:** If you have 5 apples, the number "5" is a Natural Number.
* **Note for Slow Learners:** If you can count it on your fingers, it’s a Natural Number.

## 2. Whole Numbers ($\mathbb{W}$)
**Natural Numbers + Zero**
The only difference between Natural and Whole numbers is the number **0**.

* **Definition:** All natural numbers including zero.
* **Symbol:** $\mathbb{W} = \{0, 1, 2, 3, 4, \dots\}$
* **Simple Example:** If you eat all your apples, you have **0** apples left. That "0" makes the set "Whole."
* **Memory Trick:** The word **"Whole"** has an **"o"** in it. That "o" looks like the number **0**.

<Practice 
  type="input" 
  question="Is **0** a natural number? (Type 'yes' or 'no')" 
  answer="no" 
  hint="Natural numbers start from 1. Whole numbers start from 0."
/>

---
## 3. Integers ($\mathbb{Z}$)
**The "Direction" Numbers**
Integers include positive numbers, zero, and their "twins"—negative numbers. We use these when we need to show direction (like profit vs. loss or above vs. below sea level).

* **Definition:** All whole numbers and their negative opposites.
* **Symbol:** $\mathbb{Z} = \{\dots, -3, -2, -1, 0, 1, 2, 3, \dots\}$
* **Simple Example:**
    * If you have $10$, it is +10.
    * If you owe someone $10$, it is -10.
* **Note for Slow Learners:** Integers never have decimals or fractions. They are "clean" numbers.

[Image of a number line showing positive and negative integers]

---

## 4. Rational Numbers ($\mathbb{Q}$)
**The "Fraction" Numbers**
The word "Rational" comes from the word **"Ratio."** Any number that can be written as a simple fraction is a Rational number.

* **Definition:** Any number that can be written in the form $\frac{p}{q}$, where $p$ and $q$ are integers and $q \neq 0$.
* **Key Feature:** When written as a decimal, they either **stop** (like 0.5) or **repeat** (like 0.333...).
* **Examples:**
    * $\frac{1}{2}$ (which is $0.5$)
    * $\frac{3}{4}$ (which is $0.75$)
    * $5$ (Because it can be written as $\frac{5}{1}$)
* **Note for Slow Learners:** Every number we have talked about so far (1, 0, -5) is also a Rational Number because you can put a "1" under it.

---

## 5. Irrational Numbers ($\mathbb{P}$)
**The "Crazy" Numbers**
These numbers are the opposite of Rational. You **cannot** write them as a simple fraction.

* **Definition:** Numbers that cannot be expressed as $\frac{p}{q}$.
* **Key Feature:** When written as a decimal, they go on forever without ever repeating a pattern.
* **Examples:**
    * $\pi$ (Pi): $3.14159265\dots$
    * $\sqrt{2}$: $1.41421356\dots$
* **Note for Slow Learners:** If you try to write an irrational number as a decimal, your calculator screen will fill up with random numbers and never stop!

---

## 6. Real Numbers ($\mathbb{R}$)
**The "Complete" Map**
If you take all the Rational numbers and all the Irrational numbers and put them in one big bag, you have the **Real Numbers**. Every point on a number line is a Real Number.

---

### Summary Table for Students

| Number Type | Symbol | Starts With... | Includes Negatives? | Includes Fractions? |
| :--- | :---: | :--- | :---: | :---: |
| **Natural** | $\mathbb{N}$ | $1, 2, 3...$ | No | No |
| **Whole** | $\mathbb{W}$ | $0, 1, 2...$ | No | No |
| **Integers** | $\mathbb{Z}$ | $\dots -1, 0, 1 \dots$ | **Yes** | No |
| **Rational** | $\mathbb{Q}$ | $\frac{1}{2}, 0.5, 4$ | **Yes** | **Yes** |
| **Irrational**| $\mathbb{P}$ | $\pi, \sqrt{2}$ | **Yes** | No (cannot be a fraction) |

---

### Teacher's Tip for "WEXLS" Adaptive Logic:
For slow learners, use a **"Russian Doll"** analogy. 
1. The smallest doll is **Natural**. 
2. You put it inside a bigger doll called **Whole** (adds 0). 
3. You put that inside a bigger doll called **Integers** (adds negatives). 
4. You put that inside **Rational** (adds fractions). 
5. **Irrational** is a separate doll standing alone.
6. The **Box** they all come in is **Real Numbers**.
